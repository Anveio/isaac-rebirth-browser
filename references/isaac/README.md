# Installed game reference material

The base reference set was extracted from the eight base Rebirth archives only.
The Steam installation also has Afterbirth and Afterbirth+; their overlay archives
were not supplied during this extraction. No saved games or Steam account files
are included. The manifest records source archive and extracted file hashes.

The full installed DLC extraction remains local under the ignored `extracted/`
directory. The base archive set and current Steam build identify the observed
installation; historical version parity and gameplay behavior are unverified.
