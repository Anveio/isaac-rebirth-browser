# Pickup and item interactions

An inventory of how bombs, tears, pickups, cards/runes, Blank Card and The
Battery interact in base Rebirth, with the port's state for each. Every row
marked *observed* comes from the original game through the
`pickup-interactions` suite's sandbox (below), not from wiki knowledge.

## Sandbox

`tools/original/pickup-interaction-scenarios.py` rewrites base Challenge 1 as
"Sandbox" (starting items, starting card or rune, every curse filtered) and the
base Start Room record (index 80 of `00.special rooms.stb`: extra spawns, and
optionally a 26x14 shape). Both games read the same generated bytes; they are
derived from the local original resources and stay in `.cache`.

* **Play it:** `npm run playtest:sandbox` (default preset `sandbox-2x2`: Blank
  Card, The Battery and Jera in a 2x2 Start Room with corner pickups and a Lil
  Battery), then open the printed URL and choose Challenges, Sandbox. Any
  preset in the scenario file works with `--preset NAME`. The page hook is
  `/?sandbox=URL` for a JSON `{challengesXml, specialRooms}` (`--out FILE`
  writes one).
* **Watch it against the original:**
  `npm run playtest:video -- --case RUN/pickup-interactions/scenarios.json#sandbox-2x2-fixed`.
* **Grade it:** `npm run test:e2e -- pickup-interactions` (fixed boot epoch plus
  one OS-random epoch per case). Each case is one boot; interactions that do not
  disturb each other share a boot, and each interaction is graded on its own
  labels: player position, inventory, hearts, active ID/charge/reserve,
  pockets, watched collectibles, live bombs and pickups (positions within 2-4
  world units). The original must also show the interaction (a coverage
  predicate), so a case that stops exercising it reports `uncovered`, not pass.

"All unlocks" is not modelled: both games run a fresh profile. Challenge
starting items and cards ignore achievements (Jera needs achievement 90 to drop
naturally), so the combos run; pools and natural drops stay fresh-profile.

The original admits the 26x14 Start Room record as the run's first room
(28x16 grid, Isaac enters at world 320,400) and so does the port.

## Blank Card and runes

In base Rebirth, **Blank Card (286, 4 charges) triggers the held rune**: with
Jera held, Space discharged the Blank Card (4 to 0), duplicated every pickup in
the room and kept the rune in the pocket. With The Battery's reserve charge, the
use spends the reserve (4 to 0) and keeps the main charge. A later Q then uses
the rune itself and duplicates the duplicates. There is no separate item for
runes in Rebirth. The separate item is Clear Rune (Afterbirth), which arrived
when Afterbirth stopped Blank Card from copying runes; neither change is in
base Rebirth, which is what the port targets.

The active-item key is Space; Q uses the pocket. Using the active slot (HUD,
charge, use effects) belongs to the active-item work in
[active-items.md](active-items.md). Blank Card's leaf calls the same UseCard
as the pocket for the ported cards; the Blank Card + Jera combo is still
pending on two placement frontiers (see the inventory).
