## Remaining limits

Transient18 seed/callback is explicitly unobserved at presentation-end Native
RAM. Its absence never passes as zero; actual Browser background data is kept
separately. The complete-history cap and uncomputed fullRGBA stay explicit
diagnostics. No full mixed-audio, speaker, whole shared-MT, mixed-grid dispatch,
Player/NPC damage or death, restored TNT/reentry or complete TNT parity is claimed.
Original resources, captures, binaries, disassembly and submitted PCM remain
local; only public inputs and reconstructed tool/runtime Source are published.

Run the focused gate with `npm run test:e2e -- tnt --no-build
--production-directory FROZEN`. Its complete recorded bank replays with
`--scenarios SAVED_BANK`; `--case` keeps a declared subset without OS credit
for filtered-out cases. Source/library/case/clock-identical Native reuse is
available only for a recorded single selected case with prior passing actual
provenance. Fresh Native keeps the unchanged4GiB after-copy reserve. The registered runner
owns the sole host slot; the driver does not acquire a nested slot. Without
`--production-directory`, the gate uses the normal built `dist/` snapshot. No prior
research result is silently regraded by this new registered producer.
