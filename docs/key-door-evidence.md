# Ordinary library key locks

Fresh Isaac now spends one naturally collected ordinary key when approaching a
simple key lock from its matching outward direction. The check runs after full
actor callbacks and uses the room's actual combat-clear state. Admission,
return and revisit retain the opened door without another charge. Golden keys,
double-chain locks and item overrides remain separate.

The runtime depends on integrated NPC PR26's actual room-clear field and on
inventory's regular-key admission/collection callback. Raw STB selectors keep
their authored subtype; native actor/constructor observations never enter the
production simulation.
