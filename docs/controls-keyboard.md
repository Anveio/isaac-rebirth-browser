# Keyboard Controls

The keyboard owner has 24 actions with two physical bindings each. Options → Controls selects the actual Keyboard device; its configuration page changes the bindings used by movement, shooting, bomb, active-item and pocket consumers. Fixed menu navigation has separate actions: Confirm is Space/Enter and Back is Escape. Changing a configurable binding does not rewrite those menu actions.

Configuration waits for a new physical key. Escape is a binding candidate while waiting. The raw-key scan chooses the lowest new GLFW key number, independently of event arrival order. Binding a key clears that key from both columns of other configurable actions. Back refuses an incomplete configuration; Defaults restores the constructor's binding table. Successful Back saves the complete 24-by-2 Keyboard record through the separate input-configuration owner.

Browser persistence uses origin-local `isaac-rebirth.inputconfigs.dat.v1`, independently of audio/display preferences. Its bounded text format preserves the native `KeyConfigs`/`Controller` language and all 48 signed attributes. Load precedes Keyboard construction; trace/replay retain immutable boot input configurations. The parser admits complete records. Unknown disconnected device names can be retained without advertising a connected controller.

The focused canvas captures supported physical keys, including modifiers. Owned releases follow the key across focus changes; canvas/window blur and hidden-document transitions release owned keys. Notice buttons retain their native keyboard operation. Legacy Title/Profile/Main/Character/Seed/Pause physical menu aliases remain a separate bounded path.
