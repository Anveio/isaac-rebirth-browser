# Card and Pill game-level scenarios

`npm run test:e2e -- pockets` uses the existing item-composition driver,
fresh Original processes and an immutable production browser build. `card-pill-init`
and `pocket-collection` run one mode. Every run includes both fixed phases,
retained unfiltered OS epochs, and a newly journaled unfiltered OS epoch. Replay
the exact bank with `--scenarios PATH`; replay never draws new entropy.

Both games receive the same declared XML, full Special-room catalogue, public
menu route and gameplay actions. Normal cases enter the declared seed through
the real seed dialog; Challenge cases retain their unfiltered admission. Native
observations never supply browser state, RNG, actors or inputs. The existing
readback checks real delivered input, commands, complete journals and resources.

The Init cohort appends ten distinct authored groups to the original starting
room: explicit Card families, random Card, and explicit/random Pill colors.
Collection uses three distinct cells and short movement pulses separated by
released input. Actual contacts, held changes, capacity spills, AD0 and copied
Sprite7E0/UseItem presentation are observed independently in both games. A
missing required witness fails; unsupported evidence is listed as unavailable,
never counted as equality. Source actor identities are kept within their actual
room/lifetime, so later-room selector reuse does not match an earlier actor.

The durable bank adds an explicit paired public SFX preference: fixed phase0
uses0, fixed phase1 uses1, and fresh OS cases use0.5 or1. This is a new preference
declaration; gameplay tapes/resources and retained entropy are unchanged.
Card sound8 and Pill sound252 request volume1, delay2, pitch1 and nonlooping
samples. A unique actual sample owner is compared; ambiguity stays unavailable.
Sound8 still consumes its single-sample selection draw. Native raw Game+A1D8
owns the sound-override branch; public Challenge ID is not a substitute.
Request/slot/sample settings do not prove backend playback or PCM equality.
Mute is recorded and cannot satisfy a positive playback assertion.

Capacity2 modifiers, arbitrary pocket effects, save/reentry, private callback
invocation ledgers, backend playback/PCM and full-frame pixels have separate
coverage. Holding an item does not prove every effect implemented. Raw pose and
phase witnesses are retained while exact source position integration remains
unresolved; this suite does not claim full-frame or exact physics parity.

Migration lineage retains the earlier research reports unchanged: H12 Init
301553 checks/24 unavailable obligations; H12 collectionv1 119748/3697 failures;
corrected H8ec collectionv1 120968/3279 failures; corrected separated collection
292059/28 unavailable obligations. The old whole-tape grades remain evidence,
including room exits, the prior missing Pill and unreached v1 AD0 refresh.
The source callback fix distinguishes guarded refusal AL0 (ordinary mass
response) from successful collection or positive AD0 AL1 (veto), with dead31F
veto before either callback. It adds no movement lock or animation timing hack.

The additional pocket-refused-contact-fixed-phase0 case retains the exact earlier
v1 tape, resources, epoch and phase. It requires actual guarded contact response
against a fresh Original, plus held, copied pose and sound assertions. Its
known-unreached AD0 refresh is unavailable in that scope; the old strict report
is retained, never regraded. Separated cases keep all their selected minima.

An explicit `--wasm-node WASM --wasm-sha SHA` fallback reuses the existing
public WASM boot/key/text/tick executor. It retains the same functional laws
and an independent Original capture. `--reuse-original DIR` permits exactly
one identical closed declaration, checked by the normal Native readback; it
never feeds Native observations into WASM. Node mode declares DOM, renderer,
PNGs, audio backend and PCM unavailable. It does not replace browser coverage.


Current scoped evidence covers three of the eleven declared cases. The retained
same-v1 refusal regression passes 9,349 functional checks against an independently
captured Original using the qualified scalar WASM through the public ABI. It
observes Card1→Pill1→Card40, two spills, three sound requests and the first guarded
Pill response. The separated fixed-phase0 and retained recorded0 cases each
independently pass 29,385 functional checks. The other eight cases remain obligations until their own
captures and comparisons complete. The AL report retains twelve unavailable entries,
including its then-stale counterpart label; the comparer now verifies and pins
the independent declaration before retiring that label. Unreached same-v1 AD0
refresh, browser/DOM/rendering, backend playback and PCM remain unqualified.
